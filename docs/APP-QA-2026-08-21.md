## Detailed findings

### [P2] Genuine daylight theme remains missing

- **Location:** `lib/core/theme/`, app-wide presentation.
- **Category:** Theming / accessibility.
- **Impact:** Sporve is used outdoors; an obsidian-only interface can lose
  legibility in direct sunlight even when measured dark-theme contrast passes.
- **Standard:** `PRODUCT.md` field-use requirement and `DESIGN.md` theme contract.
- **Recommendation:** Add a real light token set and test semantic token pairs in
  both modes. Do not mechanically invert dark grays.
- **Suggested command:** `$impeccable colorize`.

### [P2] Optional WebAssembly build is not compatible

- **Location:** transitive web implementations of `ua_client_hints` and
  `get_storage`.
- **Category:** Performance.
- **Impact:** The current JavaScript release is valid, but Sporve cannot adopt
  Flutter's Wasm delivery path without replacing or upgrading these packages.
- **Recommendation:** Keep the standard release target for now; evaluate
  compatible package versions before enabling Wasm in CI.
- **Suggested command:** `$impeccable optimize`.

### [P2] Native assistive-technology evidence is outstanding

- **Location:** iOS and Android release candidates.
- **Category:** Accessibility / responsive design.
- **Impact:** Flutter semantics tests and the web accessibility tree cover the
  repaired controls, but they do not replace VoiceOver, TalkBack, dynamic type,
  keyboard, and device-return checks on store binaries.
- **Recommendation:** Run a short native matrix at 100% and 200% text scale,
  including pricing, sign-in, booking, payment return, Connect resume, and
  cancellation.
- **Suggested command:** `$impeccable audit`.
